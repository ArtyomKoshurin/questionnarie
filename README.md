# Запуск проекта

## 1. Настройка окружения

1. Создайте файл `.env.local` в директории `infra/local`
2. Заполните его секретами, используя `.env.example` как пример

## 2. Развёртывание контейнеров

Запустите оркестрацию через docker-compose:

```
docker compose --env-file ./infra/local/.env.local -f docker-compose.local.yml up --build -d
```

## 3. Настройка бэкенда

1. Создайте суперпользователя в контейнере бэкенда
2. Наполните БД необходимыми данными через админ-зону
